# 새터미널 SETerminal

AI 코딩 도구(Claude Code, Codex, Gemini CLI 등)를 위해 만든 Windows 터미널의 설치 파일을 배포하는 저장소입니다.

## 다운로드

- **웹사이트: https://seterminal-website.vercel.app**
- **[최신 버전 설치 파일](https://github.com/JeaSungLEE/SETerminal-releases/releases/latest/download/SETerminal_x64-setup.exe)** (Windows 10 1809 이상 · Windows 11, 64비트)
- [모든 릴리즈와 변경 내역](https://github.com/JeaSungLEE/SETerminal-releases/releases)

설치하면 이후 새 버전은 앱이 자동으로 받아 둡니다. 관리자 권한은 필요 없습니다.

Windows SmartScreen이 "알 수 없는 게시자" 경고를 띄우면 **추가 정보 → 실행**을 누르세요.

---

이 저장소에는 자동 빌드 결과물만 올라옵니다. 설치된 앱이 각 릴리즈의 `latest.json`으로 업데이트를 찾으므로, 릴리즈 파일을 직접 수정하거나 지우지 마세요.
